 Project 4: Diamond Price Analysis

 Overview
This project focuses on analyzing the Diamonds dataset using Exploratory Data Analysis (EDA). The objective is to understand how different diamond characteristics such as carat, cut, color, clarity, depth, and table influence diamond prices through statistical analysis, data cleaning, and visualization.

---

 Objective
- Analyze the factors affecting diamond prices.
- Clean the dataset by handling missing values and duplicate records.
- Detect and treat outliers.
- Analyze categorical and numerical features.
- Compute statistical measures.
- Visualize relationships between different variables.
- Generate business insights based on the analysis.

---
 Dataset
- **Dataset Name:** diamonds.csv
- **Source:** Kaggle / Seaborn Dataset
- **Description:** The dataset contains information about diamonds, including carat weight, cut, color, clarity, dimensions, and price, which are used to analyze the factors influencing diamond prices.

 Data Cleaning
The following data cleaning steps were performed:
- Checked for missing values.
- Removed duplicate records.
- Identified outliers using box plots.
- Treated outliers using the IQR method.
- Verified data consistency before analysis.

---

 Business Insights
- Carat weight has the strongest positive influence on diamond price.
- Diamonds with better cut quality generally have higher prices.
- Higher clarity grades are associated with more valuable diamonds.
- Color and clarity together contribute significantly to pricing.
- Correlation analysis identified the most influential features affecting price.

 Conclusion
This project successfully analyzed the Diamonds dataset using Exploratory Data Analysis (EDA). Data cleaning, statistical analysis, outlier detection, correlation analysis, and visualization provided valuable insights into the factors affecting diamond prices. The findings can help businesses understand pricing patterns and support better decision-making.
