 Project 2: Titanic Data Cleaning & Passenger Analysis

 Overview
This project focuses on cleaning and analyzing the Titanic dataset using Python. The objective is to understand passenger survival patterns by performing data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization.

---

 Objective
- Read and explore the Titanic dataset.
- Handle missing values and duplicate records.
- Detect and treat outliers.
- Filter passengers based on age, gender, and passenger class.
- Group data using `groupby()`.
- Calculate survival statistics.
- Create meaningful visualizations.
- Generate an EDA report with key findings.

---

 Dataset
- **Dataset Name:** Titanic.csv
- **Source:** Kaggle Titanic Dataset
- **Description:** The dataset contains passenger details such as age, gender, class, fare, and survival status, which are used to analyze survival trends.

---

 Data Cleaning
The following data cleaning steps were performed:
- Checked for missing values.
- Filled or removed missing values where necessary.
- Removed duplicate records.
- Identified and treated outliers.
- Verified data consistency.

---

 Data Analysis
The following analyses were performed:
- Passenger survival by gender.
- Passenger survival by class.
- Age distribution of passengers.
- Fare distribution.
- Survival statistics using grouping and aggregation.

---
 Visualizations
The following visualizations were created:
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Box Plot

---


 Insights
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had better survival chances compared to second- and third-class passengers.
- Younger passengers generally had higher survival rates.
- Missing values were successfully handled, improving data quality.
- Data visualizations helped identify important survival trends.

---
Conclusion
This project successfully cleaned and analyzed the Titanic dataset using Exploratory Data Analysis (EDA). The analysis revealed significant relationships between passenger survival, gender, age, and passenger class. The project demonstrates how data cleaning and visualization can support meaningful data-driven insights.
