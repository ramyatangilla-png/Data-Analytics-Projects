 Project 3: Wine Quality Exploratory Data Analysis

 Overview
This project explores the Wine Quality dataset using Exploratory Data Analysis (EDA). The goal is to understand how different physicochemical properties influence wine quality through statistical analysis, correlation analysis, data visualization, and feature exploration.

---

 Objective
- Explore the Wine Quality dataset.
- Perform descriptive statistical analysis.
- Calculate the correlation matrix.
- Identify highly correlated features.
- Detect and analyze outliers.
- Filter and sort the dataset.
- Create visualizations to understand feature relationships.
- Draw meaningful observations and conclusions.

---

 Dataset
- **Dataset Name:** WineQT.csv
- **Source:** Kaggle / UCI Machine Learning Repository
- **Description:** The dataset contains physicochemical properties of red wine along with quality ratings assigned by wine experts.

 Dataset Features
- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality

 Key Insights
- Alcohol content showed a positive relationship with wine quality.
- Volatile acidity had a negative impact on wine quality.
- Some features exhibited strong correlations, helping identify important quality indicators.
- Outliers were identified and analyzed to improve understanding of the dataset.
- Data visualizations made it easier to identify trends and relationships among variables.

 Conclusion
This project successfully analyzed the Wine Quality dataset using Exploratory Data Analysis techniques. Statistical measures, correlation analysis, outlier detection, and visualizations provided valuable insights into the factors influencing wine quality. The analysis demonstrates the importance of data exploration before applying predictive models.
